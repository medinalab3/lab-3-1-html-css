DESCRIPCIÓN
-----------
Este proyecto es una página web básica creada como parte de la tarea de
assessment del Módulo 3. La página fue construida en Visual Studio Code
y gestionada con control de versiones (Git/GitHub). Demuestra el uso de:

1. Sintaxis básica de HTML: etiquetas de apertura y cierre, atributos y
   valores (ej. <html>, <head>, <body>, <h1>, <p>, <ul>, <li>, <a>).

2. Semántica de HTML5: uso de etiquetas con significado propio, como
   <header>, <nav>, <main>, <section>, <article> y <footer>, en lugar
   de <div> genéricos.

3. Características nuevas de HTML5: <video>, <audio>, <canvas>,
   <figure> y <figcaption>. Los comentarios dentro del archivo
   "index 3.1.html" explican qué hace cada etiqueta y por qué es una
   mejora sobre HTML4 (por ejemplo, video y audio nativos sin necesidad
   de plugins como Flash).
